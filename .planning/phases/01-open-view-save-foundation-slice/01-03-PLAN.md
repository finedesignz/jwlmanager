<objective>
Bind `jwlCore` from `libs/` via `libloading` with arch-aware `(OS, ARCH)` selection (fixing the Python bridge's arch-blind bug), resolve its symbols and read its version — load + resolve only, no merge call (D-12). Expose it as a lazy `check_jwlcore()` command returning ONE unified `JwlCoreStatus` shape so a missing/wrong-arch binary is a UI status (`loaded: false`), not a startup crash and not an Err.

Output: `jwlcore/loader.rs`, the `check_jwlcore` command returning the unified status, bundled `libs/*` resources, and per-target selection tests including the arm64-windows non-loaded status.
</objective>
