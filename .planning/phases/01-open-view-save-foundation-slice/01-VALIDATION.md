# Phase 1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Rust: `cargo test` (built-in) + `cargo clippy` + `cargo fmt --check`. Frontend: `vitest`. E2E round-trip: Rust integration tests under `app/src-tauri/tests/`. |
| **Config file** | none yet — Wave 0 scaffolds `app/src-tauri/Cargo.toml`, `app/package.json`, `app/vitest.config.ts` |
| **Quick run command** | `cd app/src-tauri && cargo test` |
| **Full suite command** | `cd app/src-tauri && cargo fmt --check && cargo clippy -- -D warnings && cargo test && cd .. && npm test` |
| **Estimated runtime** | ~90 seconds (cold Rust compile dominates; warm ~20s) |

---

## Sampling Rate

- **After every task commit:** Run `cd app/src-tauri && cargo test`
- **After every plan wave:** Run the full suite command
- **Before `/gsd-verify-work`:** Full suite must be green on x64; CI green on all four matrix legs
- **Max feedback latency:** 120 seconds
