<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| React frontend → Tauri command | Selection ids, language, and edition symbol cross here as untrusted input |
| Tauri command → rusqlite | SQL construction boundary; the archive is irreplaceable user data |
| bundled `res/resources.db` → catalog | Read-only, app-shipped; trusted content but still parameterized |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Tampering | `db/favorites.rs` SQL | high | mitigate | Every value bound via `params_from_iter`; only the IN-clause placeholder COUNT is dynamic |
| T-07-02 | Tampering | favorite add/remove commands | high | mitigate | Commands accept typed ids and edition fields only — no table or column name crosses the IPC boundary |
| T-07-03 | Denial of Service | archive integrity under FK-off | high | mitigate | `PragmaGuard` wraps every FK-off region; PRAGMAs survive rollback so the guard is mandatory |
| T-07-04 | Elevation of Privilege | mutation escaping the preview envelope | high | mitigate | `dry_run_*` uses `unchecked_transaction` that is never committed; only `*_apply` commits |
| T-07-05 | Tampering | duplicate favorite hitting `UNIQUE(TagId, LocationId)` | medium | mitigate | Typed `FavoriteDuplicate` raised by an explicit pre-INSERT SELECT |
| T-07-06 | Repudiation | double-fired destructive apply | medium | mitigate | `EditPreviewDialog`'s synchronous `busyRef` guard preserved through the rename |
| T-07-SC | Tampering | npm/cargo installs | high | mitigate | This plan declares no new dependency; if one becomes necessary, stop and add a blocking human legitimacy checkpoint |
</threat_model>

<schema_gate>
Schema-affecting: Task 2 INSERTs into `Tag`, `Location`, and `TagMap`. Composite-constraint hazards: `TagMap` `UNIQUE(TagId, Position)`, `UNIQUE(TagId, NoteId)`, `UNIQUE(TagId, LocationId)`, plus the CHECK that exactly one of PlaylistItemId/NoteId/LocationId is non-NULL (a Favorite has `NoteId IS NULL`).
</schema_gate>
