<objective>
Ship Clean and Mask (EDIT-06) — the two archive-wide, selection-free text operations — and give Mask the strongest confirmation friction in the app.

Purpose: Mask is the single most irreversible operation the app will ever have: archive-wide, random, destroys all user-authored text, no undo. The Python guards it with one Yes/No; per D7-08 this app strengthens that to a dry-run preview plus a case-sensitive typed confirm plus a destructive accent, because friction should be proportional to irreversibility.
Output: `db/scrub.rs`, two command pairs, `EditPreviewDialog`'s `requireTypedConfirm` mode, and the Clean/Mask Utilities items wired live.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Utilities menu → archive-wide command | A selection-free op reaches every user-authored text row in the archive |
| archive text → Rust transform → rusqlite | Archive-sourced strings flow through the transform and back as bound parameters |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-19 | Tampering | irreversible archive-wide mask committed by accident | critical | mitigate | Dry-run preview with row counts, case-sensitive typed `MASK` confirm that Enter cannot bypass, destructive accent border, `busyRef` double-fire guard |
| T-07-20 | Tampering | archive text interpolated into SQL | high | mitigate | Values transformed in Rust and bound as parameters; SQL is never built from archive text |
| T-07-21 | Tampering | mask/clean straying into publication body text | high | mitigate | Column allowlist enforced in source and asserted by a test comparing publication tables before/after |
| T-07-22 | Denial of Service | panic on malformed Unicode in per-row code | medium | mitigate | `.expect` confined to `LazyLock` static regex compiles per `labels.rs` precedent; clippy denies `unwrap_used`/`expect_used` elsewhere |
| T-07-23 | Information Disclosure | weak masking leaving text recoverable | low | accept | Mask is a privacy convenience matching the Python's behavior, not a cryptographic guarantee; documented in the module doc |
| T-07-SC | Tampering | npm/cargo installs | high | mitigate | No new dependency planned (hand-rolled PRNG per `time.rs` precedent); any install requires a blocking human legitimacy checkpoint |
</threat_model>
