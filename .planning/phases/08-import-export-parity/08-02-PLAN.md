<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User-supplied `.txt` file → parser | Untrusted external content: pipe-split fields and bracket-tag headers |
| React frontend → Tauri command | Resolved paths and optional selection ids |
| Tauri command → rusqlite | SQL construction boundary over irreplaceable user data |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-09 | Tampering | Bookmarks parser | high | mitigate | Exactly-12-field validation before any SQL; a hand-crafted line carrying an unescaped `|` fails the count check and aborts the whole import rather than landing shifted fields |
| T-08-10 | Tampering | Annotations record scanner | high | mitigate | Explicit boundary scan with required-key validation; a truncated or unterminated record is a typed `ImportMalformed`, never a partial insert |
| T-08-11 | Tampering | import SQL for both categories | high | mitigate | All parsed values bound via `params_from_iter`; only placeholder counts are dynamic |
| T-08-12 | Elevation of Privilege | mutation escaping the preview envelope | high | mitigate | `dry_run_*` never commits; only `*_apply` commits |
| T-08-13 | Tampering | wire-format drift silently corrupting user files | high | mitigate | Byte-exact golden-fixture assertions per category, plus an explicit per-category end-sentinel flag |
| T-08-SC | Tampering | cargo/npm installs | high | mitigate | No new dependency in this plan; a need for one halts for a blocking human legitimacy checkpoint |
</threat_model>
