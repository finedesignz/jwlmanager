<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User-supplied Highlights `.txt` → parser | Untrusted external content driving a DELETE-on-geometric-predicate code path |
| React frontend → Tauri command | Resolved paths and optional selection ids |
| Tauri command → rusqlite | SQL construction over irreplaceable user data |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-14 | Tampering | range-merge driven by external input | high | mitigate | Field count and numeric parse validated before any SQL; the merge runs only inside the transaction and only on validated token integers, via the single Phase-7-tested primitive |
| T-08-15 | Denial of Service | absorbed-row DELETE removing more than intended | high | mitigate | `merge_block_ranges` deletes exactly the ids `plan_merge` returned, scoped to one `(Identifier, LocationId)`; dedicated geometry tests assert the surviving set |
| T-08-16 | Tampering | Highlights parser field shift | high | mitigate | `^(\d+\|){6}` shape guard plus an exact-13-field count check; a mismatch is a typed error, never an indexed panic |
| T-08-17 | Elevation of Privilege | mutation escaping the preview envelope | high | mitigate | `dry_run_import_highlights` uses a never-committed `unchecked_transaction` under `PragmaGuard` |
| T-08-18 | Tampering | import SQL | high | mitigate | All parsed values bound via `params_from_iter` |
| T-08-SC | Tampering | cargo/npm installs | high | mitigate | No new dependency; the GUID comes from the shipped hand-rolled `guid.rs` |
</threat_model>
