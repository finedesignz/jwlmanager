<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User-supplied Notes `.txt` → parser | The richest untrusted surface: bracket headers, tag lists, multi-range geometry, and a bulk-delete instruction |
| React frontend → Tauri command | Resolved path, optional selection ids, and the bucket-delete opt-in |
| Tauri command → rusqlite | SQL construction over irreplaceable user data |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-19 | Denial of Service | file-driven bulk delete of a title bucket | high | mitigate | The bucket delete is never inferred from the file alone — it requires an explicit user opt-in, is surfaced as a real `deleted` count in the preview, and the GLOB pattern is a bound parameter |
| T-08-20 | Tampering | multi-range parse driving geometric DELETEs | high | mitigate | Every sub-range's identifier and tokens are parsed to integers with typed failure before any SQL; merges run only through the Phase-7 primitive |
| T-08-21 | Tampering | Notes header/body parser | high | mitigate | Required-key validation and boundary scanning; an unparseable record is a typed `ImportMalformed`, never a partial insert |
| T-08-22 | Tampering | import SQL incl. the GLOB bucket predicate | high | mitigate | All values bound via `params_from_iter`; only placeholder counts are dynamic |
| T-08-23 | Elevation of Privilege | mutation escaping the preview envelope | high | mitigate | `dry_run_import_notes` uses a never-committed `unchecked_transaction` under `PragmaGuard`, and takes the same bucket parameter as the apply so the preview cannot understate the delete |
| T-08-SC | Tampering | cargo/npm installs | high | mitigate | No new dependency in this plan |
</threat_model>
