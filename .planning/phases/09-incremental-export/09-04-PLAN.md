<ui_surface>
No UI-SPEC exists for this phase; the surface is small and is specified here against the
shipped conventions.

The incremental flow adds exactly one action per eligible category, sitting beside the
existing "Export…" action in `CategoryList`, labelled with the same trailing-ellipsis
convention the component's own comment documents for actions that open a file picker.
Its interaction sequence is: open a .txt picker for the prior export file, then the
existing save dialog for the destination, then invoke, then render the summary. A
cancelled picker at either step aborts with no backend call.

The summary reuses the shipped `EditPreviewDialog` presentation conventions rather than
introducing a new visual language, and carries three counts plus one plain sentence
disclosing that removals are not representable in the file. Errors route through the
existing `onError` and `ErrorBanner` path, identical to a malformed import file.

Read `~/.claude/design-preferences.md` before writing markup.
</ui_surface>
