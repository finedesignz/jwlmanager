<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UI category choice → Rust dispatch | the `Category` value chosen in the switcher crosses IPC to `list_category` |
| rapid switching → concurrent invokes | back-to-back category switches could race in-flight `list_category` calls |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-08 | Tampering | category value drives `list_category` dispatch | high | mitigate | The switcher emits only `Category` union values sourced from the enum; a non-variant value fails Rust enum deserialization at the IPC boundary (06-02). |
| T-06-09 | Denial of Service | rapid category switching races in-flight queries | low | mitigate | Switch sets the new category+rows only on the resolved result; the prior view stays intact on error, and a stale key cannot carry into the new category (selection reset). A last-write-wins swap is acceptable at solo-desktop scale. |
| T-06-11 | Tampering | stale selection key applied to a new category | high | mitigate | Selection is reset on category change (06-03 `CategoryList`), verified by `App.test.tsx`; integer keys never cross categories. |
| T-06-SC | Tampering | npm dependency installs | high | accept | Phase 6 adds no package (06-RESEARCH audit N/A); verify `app/package.json` unchanged. |
</threat_model>
