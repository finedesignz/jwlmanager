| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-05-02 | Elevation/Tampering | wrong-arch / missing lib | mitigate | merge_availability checks resolve_lib_name FIRST → MergeUnavailable, never invoke into an unloaded lib (Pitfall 3) |
| T-05-03 | Information disclosure | getLastResult() reason leaking path/SQL over IPC | mitigate | reason kept INTERNAL in MergeFailed; to_dto exposes only generic message_key (D-14) |
| T-05-SC | Tampering | package installs | accept | no new packages this phase (RESEARCH: all crates in-tree); nothing to audit |
